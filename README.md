# Te de Nihongo — Gesture Learning Prototype (User Testing)

This is a deployed prototype for user testing. Access the live app at:
https://poppop85.github.io/gesture-learning-prototype/

## Testing Flow
1. Dashboard — select a lesson
2. Teach — watch gesture demo
3. Practice — mirror gesture + quick quiz
4. Quiz — retrieval practice
5. Review — see milestone rewards

**Note:** The gesture recognition uses a mock API (simulated webcam).
All gesture demos and feedback are simulated for testing.
